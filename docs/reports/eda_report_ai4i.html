6.1 標籤之間並非完全等價（重要）

  • Machine failure == OR(五旗標) 的不一致筆數：27
  • 有故障（Machine failure = 1）但五旗標皆為 0：9 筆（未分類故障）
  • 五旗標有任一為 1 但 Machine failure = 0：18 筆（旗標與標籤不一致）
  • 同時成立的模式數分布：0 個 9,652 筆、1 個 324 筆、2 個 23 筆、3 個 1 筆

因此不能用五個模式旗標回推 Machine failure，也不能把它們放進特徵；這正是本專案要嚴格防止的標籤洩漏。

8. 物理工程特徵（初步）

  • Temp diff [K] = Process temperature − Air temperature：散熱失效（HDF）的已知判準為溫差 < 8.6 K 且轉速 < 1380 rpm。
  • Power [W] = Torque × 2π × RPM / 60：電力失效（PWF）的已知判準為功率落在 3,500–9,000 W 之外。
  • 相關係數：Power 與轉速 -0.806、與扭矩 0.979。

10. 對後續工作的啟示

  1. 標籤洩漏：TWF/HDF/PWF/OSF/RNF 必須排除於特徵之外，並以程式化 assert 保護（#5）。
  2. 極度不平衡：故障率 3.39%，主要指標採 PR-AUC 與 Recall/Precision，不使用 accuracy（#6）。
  3. RNF 限制：19 筆隨機失效本質上不可由感測特徵預測，構成 recall 上限。
  4. 類型與時間：Type 有預測價值；UDI 嚴格遞增，可作為時間切分的順序依據（#9）。
  5. 特徵工程：溫差與功率具有明確物理意義，值得在 #5 納入。
